1. Archive existing `outputs/` (excluding the robustness destination), original source, tests, metadata and input hashes. Record the Git revision and Python/package versions. Build a dedicated environment and exact dependency lock. Run the existing tests and local data checks.
2. Freshly reproduce five-state results without using component caches. Compare indices, forecasts, BICs and aggregate metrics against the archived original. Preserve both; do not overwrite the original output directory.
3. Refit HMMs with 3, 4, 5 and 6 states at every original monthly origin, three starts (seeds 42/43/44), keeping original initial training, horizon, features and chronological volatility path fixed. Save restart/convergence logs, fractional occupancy, effective sample diagnostics, complete transitions, durations, Gaussian emission redundancy and aligned-refit stability.
4. On the five-state path evaluate seven controlled HMM ablations/weight baselines plus entropy-deficit and original unfavorable baselines. Remove P and multipliers independently. Preserve the original PCA variant and separately test a floor-constrained PCA specification.
5. Estimate all nine rolling EVT configurations: q in {0.90,0.95,0.975}, window in {252,378,504}; keep normalization at 252 and the minimum 20 exceedances fixed. Save each fit/failure/fallback. Do not lower the exceedance requirement to make high-threshold fits appear successful. Distinguish full-sample descriptive fits from causal rolling series and forecast scoring.
6. Recalibrate all variants with identical original chronology and hyperparameters. Re-score experiment families on intersections of dates; additionally use a universal intersection for cross-family conclusions. Report effective coverage, current crisis detection separately from future crisis prediction, RMSE, MAE, AUC, Brier, precision, recall and F1. Fixed forecast probability cutoff 0.5; no test-period optimization.
7. Estimate paired 30-day circular block-bootstrap CIs (1,000 draws), squared-loss DM with HLN/Bartlett overlap treatment, Holm family-wise corrections (and global adjusted results), and sensitivity to 60-day blocks/HAC bandwidth. State nonsignificance as uncertainty, never equivalence. Add train-only constant/prevalence baselines and examine incremental HMM information conditional on V/T as an exploratory check.
8. Run causality tests with future perturbations and prefix comparisons, verify model/scaler training endpoints and target maturity. Audit revised-data, label semantics, initialization, PCA floors, convergence and small-tail-sample limitations.
9. Write all requested audit reports, revised manuscript sections, figures, source/data hashes, configurations and commands under `outputs/robustness/`. Preserve any found Zenodo DOI verbatim; if unavailable, mark missing author metadata explicitly. No upload or submission.

All specifications are fixed before examining the new comparisons. The already-inspected historical test period makes the new experiment a retrospective robustness study, not an untouched confirmatory holdout. Do not change the production state count based on this study. Journal/arXiv readiness is a separate assessment from completion of executable experiments.

Supplementary analysis note: after inspecting the train/test emission-density pattern, a three-month-block likelihood-difference bootstrap was added as an explicitly exploratory diagnostic. It is not represented as preregistered confirmatory inference, and does not select model parameters or the production state count.
